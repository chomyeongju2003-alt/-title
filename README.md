# 2023년 산업연관표(연장표) 분석 웹앱

한국은행이 발표한 **2023년 산업연관표(연장표, 생산자가격 기준)**를 브라우저 환경(Pyodide)에서 직접 분석할 수 있도록 구현한 정적 웹 애플리케이션입니다.

## 1. 활용 데이터 및 단위 기준
- **통합대분류 (33부문)**: `data/(표)(2023연장)투입산출표_생산자가격_통합대분류.xlsx`
- **통합중분류 (83부문)**: `data/(표)(2023연장)투입산출표_생산자가격_통합중분류.xlsx`
- **통합소분류 (165부문)**: `data/(표)(2023연장)투입산출표_생산자가격_통합소분류.xlsx`
- **기본부문 (380부문)**: `data/(표)(2023연장)투입산출표_생산자가격_기본부문.xlsx`
- **단위 체계**:
  - 거래표(총·국산·수입) 및 항목별 유발액: `백만원`
  - 각종 구조 비율·의존도·구성비: `%`
  - 투입계수 및 생산·부가가치·수입유발계수: `계수` (투입액/총투입 또는 최종수요 1단위당 유발액)
  - 영향력계수(후방연쇄)·감응도계수(전방연쇄): `지수` (전산업 평균 = 1.0 기준 상대지수)

## 2. 웹앱 사용 방법
1. **0. 투입산출표 분류 선택 및 데이터 로딩**: 대분류·중분류·소분류·기본부문 중 하나를 선택한 뒤 **투입산출표 불러오기** 버튼을 클릭합니다.
2. **1. 원자료 및 유발계수표 탐색**: 12개 시트를 전환하며 행(산업/부가가치/연쇄효과 지수)과 열(수요/투입 부문)을 검색해 정확한 수치를 조회합니다.
3. **2. 산업별 경제구조 · 연쇄효과 · 최종수요 의존도 심층 분석**: 특정 산업을 선택하면 투입구조·대외거래 비율(%), 유발계수, 연쇄효과 4분면 산업 유형, 소비·투자·수출 의존도(%), 주요 중간투입 원재료 및 중간수요 판매처 TOP 5가 자동 산출됩니다.
4. **3. 국내 생산물 최종수요 증가 파급효과 시뮬레이션**: 산업별 최종수요 증가액(단위: 백만원)을 시나리오에 추가한 뒤 파급효과 계산을 실행하여 전 산업의 생산·부가가치·수입유발액(단위: 백만원)을 산출합니다.

## 3. 주요 경제 지표 산식 (한국은행 기준)
- **부가가치율** = 부가가치계 ÷ 총투입계 × 100 (%)
- **중간투입률** = 중간투입계 ÷ 총투입계 × 100 (%)
- **국산화율** = 국산 중간투입계 ÷ 총 중간투입계 × 100 (%)
- **수입의존도** = 수입 중간투입계 ÷ 총투입계 × 100 (%)
- **수출률** = 수출액 ÷ 총산출 × 100 (%)
- **수입률** = 수입계 ÷ 총공급계 × 100 (%)
- **최종수요 항목별 의존도** = 항목별(소비·투자·수출) 생산유발액 ÷ 총 최종수요 생산유발액 × 100 (%)
- **파급효과 계산**: 부문별 유발액 = 유발계수행렬 × 최종수요증가벡터 (단위: 백만원)
