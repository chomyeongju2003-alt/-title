# 2023년 산업연관표(연장표) 분석 웹앱

한국은행이 발표한 **2023년 산업연관표(연장표, 생산자가격 기준)**를 브라우저 환경(Pyodide)에서 직접 분석할 수 있도록 구현한 정적 웹 애플리케이션입니다.

## 1. 활용 데이터
- `(표)(2023연장)투입산출표_생산자가격_통합대분류.xlsx` (33부문)
- `(표)(2023연장)투입산출표_생산자가격_통합중분류.xlsx` (83부문)
- `(표)(2023연장)투입산출표_생산자가격_통합소분류.xlsx` (165부문)
- `(표)(2023연장)투입산출표_생산자가격_기본부문.xlsx` (380부문)

## 2. 웹앱 사용 방법
1. 상단 **분류 기준 선택**에서 대분류·중분류·소분류·기본부문 중 하나를 선택하고 **투입산출표 불러오기**를 클릭합니다.
2. **1. 원자료 및 유발계수표 탐색**: 총거래표·국산/수입거래표·투입계수·유발계수 등 12개 시트를 전환하고 행(산업/부가가치)과 열(수요/투입 부문)을 검색해 수치를 확인합니다.
3. **2. 산업별 경제구조 및 전·후방 연쇄효과 분석**: 특정 산업의 부가가치율, 중간투입률, 국산화율, 수입의존도, 수출률, 수입률(%)과 생산·부가가치·수입유발계수, 영향력·감응도계수를 조회합니다.
4. **3. 국내 생산물 최종수요 증가 파급효과 시뮬레이션**: 하나 이상의 산업과 최종수요 증가액(단위: 백만원)을 시나리오에 추가한 뒤 파급효과 계산을 실행하여 산업별 생산·부가가치·수입유발액을 산출합니다.

## 3. 주요 경제 지표 산식 (한국은행 기준)
- **부가가치율** = 부가가치계 ÷ 총투입계 × 100 (%)
- **중간투입률** = 중간투입계 ÷ 총투입계 × 100 (%)
- **국산화율** = 국산 중간투입계 ÷ 총 중간투입계 × 100 (%)
- **수입의존도** = 수입 중간투입계 ÷ 총투입계 × 100 (%)
- **수출률** = 수출액 ÷ 총산출 × 100 (%)
- **수입률** = 수입계 ÷ 총공급계 × 100 (%)
- **파급효과 계산**: 생산유발액 = 생산유발계수행렬 × 최종수요증가벡터 (단위: 백만원)
